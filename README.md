# Instagram-Profile-Sorter
A simple extension for browser to sort insta profile by Reels, Videos, Photos. etc. or by likes views or a specific caption.

<h2> Installation: </h2>

1:] Enable Developer mode on your browser.
<br>
2:] Extract Extension on your pc using winrar, extract here option.
<br>
3:] On your browser select "Load unpacked".
<br>
4:] Locate and chose the extracted extension folder.
<br>
5:] Click on the extension details, and select these options.
